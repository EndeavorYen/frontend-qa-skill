## 既有資料抽樣

| 型態 | 抽樣 | console |
|---|---|---|
| 狀態：待處理 | #1（備註有內容） | 列表／詳情 → 無 |
| 狀態：已完成 | #2（備註為「（無備註）」） | 列表／詳情 → 無 |
| 狀態：已取消 | 無既有資料；以「已取消」篩選的空結果驗證 | ➖ 無此型態資料（F18） |
| 選填欄位「備註」缺漏 | #3（資料中沒有 note 欄位） | #3 → `TypeError: Cannot read properties of undefined (reading 'trim')`（F1） |
| 很長的客戶名（無空格連字號） | #3 | 列表以「…」截斷，無錯誤 |
| 不存在的 id | #999、#0（`/api/orders/0` 回 200 + 整個列表）、#abc、#-1 | #999／#0 → 同一個 TypeError（F2）；#abc／#-1 → 找不到頁面，無錯誤 |
| 極端值（自建） | 數量 0／-3／1.5、單價 -50、1e9×1e9、600 字客戶、300 字品項 | 無例外，但 F13、F14、F15 |

編輯畫面：app 沒有編輯訂單的入口（列表與詳情皆無），所以「列表、詳情、編輯」只做列表與詳情。
