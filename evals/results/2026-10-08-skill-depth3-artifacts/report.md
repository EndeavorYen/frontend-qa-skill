1. F1 [P0][bug] 連點「送出訂單」會建立兩筆相同訂單 — 一次送出變成兩張待處理訂單
2. F4 [P1][斷點] 建立訂單遇到 HTTP 500 會打開 `#/orders/undefined` — 失敗後掉進找不到頁面
3. F3 [P1][斷點] 列表在 API 失敗或離線時停在「載入中…」 — 主清單沒有錯誤、也沒有重試
4. F6 [P1][bug] 「儲存」設定沒有送出、沒有回饋，重新整理後恢復原值 — 設定頁的唯一動作沒有生效
