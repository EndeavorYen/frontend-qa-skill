## 摘要

- 覆蓋率：✅ 91 / ➖ 7 / ⛔ 0（總共 98 格）

## 最嚴重的 5 個問題

1. F10 [P1][RWD] 手機上頁尾蓋住「送出訂單」，捲到底也點不到 — 建立訂單在 320 與 390 寬做不完
2. F5 [P1][邏輯] 數量可以是負數、0 或小數 — 畫面上寫必須是正整數，訂單還是會建立，小計可以是負的
3. F1 [P1][邏輯] 「已完成」仍列出待處理 — 篩選結果不能拿來判斷哪些單做完了
4. F4 [P1][斷點] 列表 API 失敗時停在「載入中…」 — 沒有錯誤文案，也沒有重試
5. F9 [P1][邏輯] 設定按了儲存等於沒按 — 離開或重新整理就回到預設

## UI/UX 體檢摘要

- 整體 2.6 / 5；最低分的畫面：S4 建立訂單、S6 說明、S7 聯絡我們、S8 未知路由（都是 2.1）
- 最值得做的 3 項改善（完整內容見 `ux-review.md`）：
  1. 手機上不要讓頁尾蓋住送出，送出時停用按鈕，並擋下不合法的數量與單價
  2. 列表與詳情在 API 失敗時改成錯誤狀態，不要停在載入中，也不要畫出 `#undefined` 和「NT$ 非數值」
  3. 「已完成」只顯示已完成；沒有資料時寫出空狀態
