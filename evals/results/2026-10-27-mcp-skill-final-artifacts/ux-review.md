| 維度 | 分數 | 依據 |
|---|---|---|
| 視覺層級 | 4 | 每頁一個 H1，主要按鈕藍色，是列表和表單最顯眼的元素 |
| 一致性 | 2 | 主要按鈕 4px、次要 12px（F15）；詳情頁「工單」、其他頁「訂單」（F3） |
| 排版節奏 | 3 | 表單間距一致；手機詳情被長名稱撐出橫捲（F16），列表最後一列被固定頁尾蓋住（F17） |
| 回饋 | 1 | 設定「已儲存」但沒存（F11）；列表 API 失敗一直「載入中…」（F19）；離線送出沒有訊息（F20）；送出沒有送出中狀態，連點建兩筆（F6） |
| 文案 | 2 | 驗證錯誤只寫「發生錯誤」（F2）；「工單／訂單」混用（F3）；不存在的訂單顯示「#undefined」「NT$ 非數值」（F13） |

| 質感 | 3 | 乾淨、留白足；「已取消」空狀態只剩表頭（F9），提示字對比 1.56:1（F21），🗑 是 emoji 包在 DIV（F4） |

## 前五個改進

1. 每個寫入動作要有送出中、成功、失敗三種狀態，送出中停用按鈕（F6、F11、F19、F20）
2. 驗證訊息寫清楚哪個欄位、為什麼錯，前端擋下負數（F2、F5）
3. 統一按鈕圓角、「工單」改「訂單」、提示字對比拉到 4.5:1 以上（F15、F3、F21）
4. 補上空狀態和找不到資料的頁面（F9、F13）
5. 刪除改成 `<button aria-label="刪除訂單 #n">`，確認框加 `role="dialog"`、支援 Esc、焦點移入（F4、F18）
