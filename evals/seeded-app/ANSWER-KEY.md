## 計分

每跑一次，就在 `evals/results/<YYYY-MM-DD>-<label>.md` 填寫下表：

```markdown
| # | 抓到 | 對應 F 編號 | 等級差距 | 備註 |
|---|---|---|---|---|
| B1 | ✅ | F3 | 0 | |
| B2 | ❌ | | | 工具軌 T2 擋住 |
```

- **抓到**：同一個畫面、同一個現象，而且有證據。只抓到一部分（例如 B8 只提到 Esc），記為 ½。
- **等級差距**：報告的等級和答案卷的差幾級。
- **指標**：
  - 總抓到率 = 抓到數 / 21
  - P0+P1 抓到率 = 抓到的 P0、P1 數 / 6（目標是 100%）
  - 假陽性：報告中有、但實際上無法重現的問題數
  - 額外問題：答案卷沒有、但確實存在的問題。確認後補進答案卷，加上新的 B 編號
- 工具軌和未歸因的項目另外列出，不計入抓到率。
