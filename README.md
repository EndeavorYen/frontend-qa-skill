# frontend-qa

A skill that drives a real UI the way a picky user would, reports front-end bugs and UX issues, and does not modify product code. The procedure is [`skills/frontend-qa/SKILL.md`](skills/frontend-qa/SKILL.md).

## Promise

- **Effective.** It catches real front-end bugs, avoids false positives and false negatives, and every conclusion carries evidence (a screenshot, a repro spec, or a probe result).
- **Efficient.** It aims for fewer steps, fewer tokens, and faster runs.
- **Easy for agents.** Skill instructions are clear and executable as written, output formats stay stable, and errors include the cause plus a runnable next-step command.

Design rules for contributors and coding agents are in [`AGENTS.md`](AGENTS.md).
